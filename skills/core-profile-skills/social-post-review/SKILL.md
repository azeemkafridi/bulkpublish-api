# Social Post Review

Give an actionable review of social copy and its planned media or platform targets.

## Review areas

- Goal and audience alignment
- Hook, clarity, structure, voice, and CTA
- Factual support, disclosure, copyright, privacy, and potentially misleading claims
- Platform character limits, formatting, hashtags, links, and post type
- Media compatibility and required metadata
- Cross-platform duplication, inconsistent claims, or a CTA that does not work on the target platform

Use `platform-reference` and `media-preflight` for technical validation. Distinguish blocking issues from suggestions. Return corrected copy only when useful, and do not publish or schedule until the user approves the reviewed draft.
