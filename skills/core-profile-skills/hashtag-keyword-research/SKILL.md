# Hashtag and Keyword Research

Build relevant, audience-oriented keyword and hashtag recommendations for content that will be published through BulkPublish.

## Workflow

- Start with the topic, audience, intent, geography, platform targets, and campaign objective.
- Separate branded, topic, community, discovery, and campaign hashtags; avoid irrelevant or deceptive tags.
- Keep recommendations platform-specific and within each platform's caption or post limits.
- Return a reusable hashtag set plus a restrained set for each post, not a long undifferentiated list.
- Use `platform-content-adapter` to place the selected terms naturally in each variant.

Before execution, check the target channels with `manage-channels` and prepare the final copy for BulkPublish `platformContent` or drafts. Do not claim search volume or trend status without a source.
