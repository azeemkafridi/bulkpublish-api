# Social Content Strategy

Translate the user's goal into a focused social media strategy that can be executed through BulkPublish.

## Workflow

1. Identify the objective, audience, offer or topic, proof points, call to action, timeframe, and available media.
2. Choose a small set of content pillars that support the objective; avoid generic posting plans with no audience or business rationale.
3. Recommend platform roles using the platforms connected to BulkPublish. Match the format and tone to each platform rather than treating every channel as interchangeable.
4. Define a repeatable mix of formats, hooks, CTAs, and posting cadence.
5. Return an actionable brief for each planned post: purpose, audience, angle, hook, key points, CTA, platform targets, post type, and media need.

Ask only for missing information that materially changes the strategy. Clearly label assumptions and do not publish or schedule anything unless the user asks for execution.
