# Social Content Audit

Assess whether a social content system is coherent, publishable, measurable, and maintainable.

## Audit areas

- Strategy: audience, pillars, objectives, cadence, and CTA coverage
- Content: hooks, voice, repetition, accessibility, disclosures, and factual risk
- Platform fit: limits, post types, media, required titles, and channel coverage using `platform-reference`
- Operations: connected-channel health, quota, approvals, drafts, scheduled posts, failures, and unconfirmed states using BulkPublish tools
- Measurement: labels, date ranges, supported metrics, link tracking, and reporting readiness

Return findings as blocking issues, recommended fixes, and optional improvements. Do not mutate BulkPublish content or settings during an audit unless the user separately authorizes the changes.
