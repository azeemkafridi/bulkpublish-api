# Changelog

## 1.0.0

Initial release.

- Connects to the BulkPublish remote MCP server at `https://mcp.bulkpublish.com/mcp` over Streamable HTTP.
- OAuth 2.1 with Dynamic Client Registration and PKCE — no client ID to configure.
- Six reference skills: platform-reference, schedule-post, bulk-publish, manage-channels, get-analytics, check-quota.
